### Besaran dan satuan
| Besaran | SI | Konvensional | Konversi |
|---|---|---|---|
| **Aktivitas** (peluruhan per detik) | **becquerel (Bq)** = 1 peluruhan/detik | **curie (Ci)** | **1 Ci = 3,7 x 10^10 Bq = 37 GBq**; 1 Bq = 2,7 x 10^-11 Ci = 27 pCi |
| **Eksposur** (ionisasi di udara oleh foton X/gamma) | C/kg | **roentgen (R)** | 1 R = 2,58 x 10^-4 C/kg |
| **Dosis serap (D)** (energi per massa) | **gray (Gy)** = 1 J/kg | **rad** | **1 Gy = 100 rad**; 1 rad = 0,01 Gy = 10 mGy |
| **Dosis ekivalen (H_T)** | **sievert (Sv)** | **rem** | **1 Sv = 100 rem**; 1 rem = 10 mSv |
| **Dosis efektif (E)** | sievert (Sv) | rem | 1 Sv = 100 rem; 20 mSv = 2 rem |

### Rumus
- **Dosis ekivalen**: H_T = sigma (wR x D_T,R)
- **Dosis efektif**: E = sigma (wT x H_T)
- **Laju dosis** = dosis per satuan waktu (mSv/jam, uSv/jam)

### Faktor bobot radiasi (wR, ICRP 103)
| Radiasi | wR |
|---|---|
| Foton (X, gamma), semua energi | **1** |
| Elektron, muon, positron (termasuk beta) | **1** |
| Proton dan pion bermuatan (lebih dari 2 MeV) | **2** |
| **Alfa**, fragmen fisi, inti berat | **20** |
| **Neutron** | fungsi kontinu energi: **2,5 sampai 20** (puncak sekitar 20 pada 1 MeV) |

### Faktor bobot jaringan (wT, ICRP 103)
| Jaringan | wT |
|---|---|
| Sumsum tulang merah, kolon, paru, lambung, payudara | **0,12** masing-masing (total 0,60) |
| **Gonad** | **0,08** |
| Kandung kemih, esofagus, hati, tiroid | **0,04** masing-masing (total 0,16) |
| Permukaan tulang, otak, kelenjar ludah, kulit | **0,01** masing-masing (total 0,04) |
| Jaringan sisa (*remainder*) | **0,12** |
| **Total** | **1,00** |

### Waktu paruh
- **Fisik (Tp)**: waktu aktivitas turun 50%. **A(t) = A0 x (1/2)^(t/Tp)** = A0 x e^(-lambda t); **lambda = 0,693 / Tp**. Setelah n waktu paruh: **A = A0 / 2^n**.
- **Biologis (Tb)**: waktu tubuh mengeliminasi 50% (ekskresi).
- **Efektif (Te)**: **1/Te = 1/Tp + 1/Tb**, atau **Te = (Tp x Tb) / (Tp + Tb)**.

### Contoh hitungan
1. **Alfa ke dosis ekivalen**: dosis serap paru 0,2 Gy alfa. H = wR x D = 20 x 0,2 = **4,0 Sv = 400 rem**.
2. **Batas pekerja ke rem**: 20 mSv = 0,020 Sv x 100 = **2,0 rem per tahun**.
3. **Peluruhan**: I-131 (Tp 8 hari), 80 Ci disimpan 24 hari. n = 24/8 = 3; A = 80 x (1/2)^3 = **10 Ci = 3,7 x 10^11 Bq (370 GBq)**.
4. **Waktu paruh efektif**: I-131 Tp = 8 hari, Tb (tiroid) = 12 hari. Te = (8 x 12) / (8 + 12) = 96/20 = **4,8 hari**.

!PEARL **Bq dan Ci**: 1 Ci = **3,7 x 10^10 Bq**. **Gy dan rad**: 1 Gy = **100 rad**. **Sv dan rem**: 1 Sv = **100 rem** (1 mSv = 0,1 rem). **Alfa wR = 20**, foton dan beta = 1. Dosis ekivalen = wR x dosis serap; dosis efektif = wT x dosis ekivalen.
