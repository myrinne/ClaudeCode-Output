# Pathweb Normal Histology

Local study atlas for the **Histopathologist** hat (vault: `Identity/hats/pathologist.md`).

| Path | What | In git? |
|---|---|---|
| `atlas.md` | Own-words condensed notes for all 55 organs: ID clues, labelled structures, look-alikes, occ-med hooks, confusable-pairs table | yes |
| `raw/pages/<organ>.md` | Text of each NUS Pathweb page | no (gitignored, copyright) |
| `raw/images/<organ>/` | 529 reference images; `*-blank.*` = unlabelled quiz version | no (gitignored, copyright) |
| `raw/index.json` | Organ list + image filenames | no |

Source: NUS Pathweb Normal Histology, https://medicine.nus.edu.sg/pathweb/normal-histology/ , downloaded 2026-10-20 for personal study. The site is behind bot protection (Incapsula/hCaptcha), so re-downloading means passing the check in Chrome, then fetching the pages from inside that tab.
